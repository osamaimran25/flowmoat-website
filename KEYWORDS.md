# Keyword Map — flowmoat.com

**How priorities were set:** buyer intent first, then how well Flowmoat can actually back the
claim, then how hard the term looks to compete for. **No search-volume data is used.** No keyword
tool was connected when this was written. Before building any new page, check each P1 term in
Search Console (once data exists), Google Keyword Planner or Ahrefs, and reorder if volume is zero.

**Intent:** Commercial = comparing providers, close to buying · Transactional = ready to hire ·
Informational = researching the problem (blog).

**Target page:** pages marked *(new)* don't exist yet and need approval (see SEO_PLAN.md).
One primary keyword per page. Related terms go into the same page rather than getting their own.

## Rules

- One primary keyword per URL. If two pages target the same term, merge them.
- Put the keyword in the title, H1, first paragraph and meta description, once each, written
  naturally.
- Every new page links to one service page, one proof page, and gets at least two internal links
  pointing in.
